# Terra Browser

**Terra Browser** 是一款基于 **Jetpack Compose + LiquidKit + Android WebView** 构建的 Android 浏览器，完整复刻 iOS 26 / 27 Safari 的液态玻璃视觉材质、手势物理与多标签页排布交互。

## 核心特性

- **液态玻璃底部双行悬浮 Dock（`SafariBottomDock`）**
  - 地址栏支持 **左右横滑切换相邻标签页**（末页继续左滑自动新建起始页），以及 **上滑直达标签页总览**。
  - 页面滚动时自动弹性折叠为极简域名胶囊；点击或回滑展开。
  - 支持长按 `<` / `>` 查看当前标签页真实前进/后退历史栈，长按标签页按钮呼出快捷菜单。
- **流畅标签页总览与动态标签页组（`TabOverviewScreen`）**
  - 打开/选中标签页具备 **共享元素连续缩放与圆角形变过渡**。
  - 支持 **2 列弹性网格布局**、**长按拖动实时重排**（邻近卡片弹簧避让）、**置顶固定标签页** 与 **实时搜索过滤**。
  - 底部动态标签页组胶囊：左右滑动切换 `无痕浏览` / `标签页` / `dev` / `AI Tools` 或直接横向拖动胶囊时，两侧 `+` 与 `✓` 按钮自动收起，胶囊横向展开并伴随液态折射透镜滑块同步跟手。
- **完整 Safari 菜单与功能集（`SafariMenusAndSheets` / `StartPage`）**
  - 起始页包含 **个人收藏**（长按上下文预览菜单）、**隐私报告**（实时拦截追踪域名统计）与 **阅读列表**。
  - 多级 **页面菜单**（页内查找、页面缩放与玻璃透明度/深浅色调节、内容拦截器、隐藏工具栏、请求桌面网站、自适应深色模式、标签页操作、自定义菜单）。
  - **书签 / 阅读列表 / 历史记录** 抽屉支持左右滑动操作与实时持久化，支持长按网页图片/链接呼出液态玻璃预览上下文菜单。

## 构建与测试

```bash
# 运行单元测试并构建 Debug APK
./gradlew :app:testDebugUnitTest :app:assembleDebug

# 安装到连接的 Android 设备或模拟器
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
