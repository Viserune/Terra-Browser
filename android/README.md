# Terra Browser · Android

用 Android Studio 打开解压后的 `android` 文件夹。保留同级的 `shared` 文件夹，Gradle 会从中打包阅读器脚本、图片和依赖许可。

本工程使用 Kotlin、Compose、LiquidKit 和系统 WebView，支持 Android 10 及以上版本。LiquidKit 和 Backdrop 的 AAR 位于 `app/libs`。构建需要 JDK 21 和 Android SDK Platform 37，首次构建需要下载 Gradle 和 Maven 依赖。

在 Windows 的 `android` 目录运行：

```powershell
.\gradlew.bat :app:assemblePreview
```

生成的体验包位于 `app/build/outputs/apk/preview/app-preview.apk`。本地编译的 preview 使用本机调试证书。手机已装其他证书签名的同包名应用时，请使用原签名对应的安装包进行覆盖更新。

点按底部地址栏输入网址。左右划切换标签，上划打开总览。长按链接、图片、前进、后退或标签按钮可以打开相应菜单。无痕标签需要系统 WebView 支持独立配置文件。

手势、菜单、地址栏输入和全屏视频的设备回归脚本位于 `tests`。请在已安装应用的测试设备上运行，具体参数见各脚本开头。

手机地址栏支持跟手切换标签。平板宽度足够时使用顶部工具栏和标签条。长按链接可以预览、隐藏预览或打开目标。页面菜单可手动收起工具栏，再点域名恢复。

玻璃使用 LiquidKit 1.0.0-alpha.3 和匹配的 Backdrop。WebView 提供背景像素，LiquidKit 负责折射、模糊和高光。完整运行时着色效果需要 Android 13 及以上。 两个 AAR 均来自 [LiquidKit v1.0.0-alpha.3 发布页](https://github.com/egysoloman/LiquidKit/releases/tag/v1.0.0-alpha.3)，可与发布附件列出的 SHA-256 核对。

在安装 Python 和 Pillow 后，用 `python tests/safari_motion.py 设备序列号` 可验证拖动中间帧、预览和玻璃随页面滚动的采样。平板布局加 `--tablet`。

横向切换使用网页当前画面的短时快照，松手后恢复网页交互。最多缓存三张过渡图，页面从视图中移除时会释放对应缓存。

在标签总览里，当前网页会缩到对应卡片的位置。点另一张卡片可从该位置展开网页，向左划过卡片可关闭标签，短距离慢划后松手会回弹。普通浏览和无痕浏览各自记住上次选中的标签。

在手机布局的测试设备上运行 `python tests/tab_overview.py 设备序列号 --record overview.mp4` 可以复测总览动画、卡片手势和普通与无痕切换，并保存屏幕录像。

网页内从左边缘向右拖可后退，从右边缘向左拖可前进。手指拖回原位可取消。在 Android 系统手势模式下，从屏幕边缘中部开始最可靠。预览来自当前标签访问过的网页，只缓存在内存中；缓存缺失时过渡画面显示目标站点域名。用 `python tests/history_swipe.py 设备序列号 --record history.mp4` 可验证方向、取消和页面纵向滚动。

阅读长网页时，向下阅读会将工具栏收成玻璃域名条，反向滚动或轻点域名即可展开。手机在底部显示，收起后仍可左右切换标签、上划打开总览。平板在顶部显示。网页不能滚动时保持展开。用页面菜单手动收起后，工具栏会保持收起直到点按域名。可用 `python tests/reading_toolbar.py 设备序列号 --record toolbar.mp4` 复测；平板布局加 `--tablet`。

玻璃取样覆盖工具栏及其周围的网页。打开长按菜单、面板或提示框时，取样会扩展到整个可见页面。

在支持 SurfaceFlinger 呈现时间戳的测试设备上，可运行 `python tests/scroll_pacing.py 设备序列号`。脚本打开本地长网页，统计八次滑动各自的连续呈现间隔，报告中位数和第 90 百分位。两次手势之间的停顿不计入。

在「页面菜单 → 页面缩放」中，小 A 和大 A 可在 50% 到 300% 之间调整网页字号，点百分比恢复 100%。普通浏览按主机名记忆设置，无痕浏览单独保存到内存，关闭最后一张无痕标签即清除。平板页面菜单从顶部地址栏按钮下方展开。可在专用测试设备上运行 `python tests/site_zoom.py 设备序列号` 复测字号、重启和无痕隔离；平板可加 `--tablet --layout-only`。
长按标签总览中的卡片可固定或取消固定。固定的页面收成置顶的标题栏，轻扫时会保留；长按后选「关闭标签页」可关闭。平板也可以直接长按顶部标签。普通标签的固定状态会随会话保存，无痕标签只在当前会话有效。在专用模拟器运行 `python tests/tab_overview.py 设备序列号 --pins`，或在平板布局运行同一脚本并传入 `--tablet-pins`。

点总览右上角的标签组按钮可创建、切换或重命名普通标签组。长按卡片或平板顶部标签后选「移至标签组」，即可移动原页面。固定顺序、新建标签、地址栏横滑都遵循当前组。移除组时可以保留网页，也可以关闭组内页面。用 `python tests/tab_overview.py 设备序列号 --groups` 复测手机流程，平板使用 `--tablet-groups`。

在标签总览点放大镜，或回到网格顶部后向下拉开搜索框，即可按标题或网址筛选当前标签组。点结果打开原网页，点「取消」返回浏览位置。长按「完成」可批量关闭当前组或搜索结果中未固定的标签页。长按普通组的加号可从最近关闭列表恢复网页。用 `python tests/tab_overview.py 设备序列号 --search-tabs` 在专用测试设备验证。

标签总览里的加号、浏览模式切换和「完成」浮在卡片上方。上下拖动卡片时，LiquidKit 会实时折射经过按钮下方的网页预览。滑到末尾时，最后一排卡片可以完整移到按钮上方。在竖屏手机模拟器上运行 `python tests/tab_overview.py 设备序列号 --glass --glass-screens screenshots --record overview.mp4`，可对比同一按钮透过蓝、橙两张卡片时的像素并保存录像。

切走普通标签或把浏览器放到后台时，Terra 会保存该标签当前视口的缩略图和阅读位置。重启后可以直接看总览里的预览，点选一张才载入对应网页。展开时旧画面会短暂保留，网页绘制并恢复阅读位置后交接给实时内容。等待预览最多保留 2.5 秒。缩略图保存在应用缓存中，每个窗口上限 20 MiB，系统回收缓存后卡片会回到标题占位。关闭标签会删除它的缩略图。无痕标签的预览仅在内存中使用。可用 `python tests/tab_overview.py 设备序列号 --restore-previews --record restore.mp4` 复测强制停止、后台标签取色、阅读位置和慢响应时的画面交接。
安装 OpenCV 后，运行 `python tests/restored_previews.py restore.mp4` 可逐帧检查预览展开后有无闪回上一页。

长按网页链接、前进或后退按钮、标签按钮或总览卡片时，可以保持手指按下，滑到高亮的菜单项再松开执行。滑出后松开可取消，原地松手则保留菜单供点选。在超出一屏的菜单里，把手指停在上下边缘即可滚动。竖屏平板上的网页预览与操作列表并排显示。可用 `python tests/safari_motion.py 设备序列号 --menu-drag --menu-record menu.mp4` 复测单次长按和总览卡片。在同一台测试设备上单独使用 `--menu-history` 可验证从长列表中选中最早的历史记录，820 dp 宽的竖屏平板使用 `--tablet-menu` 可复测预览尺寸。

长按普通网页中的链接，选「在标签页组中打开」可把目标网页作为新标签打开在指定组，原网页留在原组。点「新建标签组」可命名后打开。手指保持按下，在分组菜单项上稍停即可展开，再滑到组名松手选中。原地松手可继续点选，返回键可退回链接菜单。无痕浏览仅提供无痕标签操作。可用 `python tests/safari_motion.py 设备序列号 --link-groups --menu-record group.mp4` 在专用测试设备复测分组、取消、冷启动和无痕隔离。

长按链接选「在新窗口中打开」，在系统最近任务里可独立切换两个窗口。每个窗口保留自己的标签、标签组和阅读位置，共享普通书签、历史记录和阅读列表。长按新窗口的标签按钮可关闭该窗口。无痕窗口的网址只在内存中交接，进程被回收后从空白页开始。可分别用 `python tests/safari_motion.py 设备序列号 --new-window` 和 `--private-window` 在专用手机模拟器复测。

书签、历史记录、阅读列表和最近关闭使用 LiquidKit。手机上的面板从半屏开始，可拖住顶部横条向上展开，短拖松手会回弹；列表滑到顶后继续下拉可以收起。接近全高时，面板逐渐变实，后面的网页缩小。宽屏使用左侧玻璃面板。左滑列表项可显示共享和删除，滑过整行可直接删除。运行 `python tests/safari_motion.py 设备序列号 --library-glass --screens screenshots --menu-record library.mp4` 可录制蓝色和橙色网页上的书签面板，并验证同一处玻璃的取色。

在竖屏手机模拟器运行 `python tests/safari_motion.py 设备序列号 --library-motion --screens screenshots --menu-record sheet.mp4`，可验证中途停住、回弹、两档停靠、列表滚动交接和横滑。脚本生成自己的本地网页，只测试删除本次生成的历史条目。

用 `--live-sheet` 可在保持面板打开时，让底层网页变色并检查实时取样。用 `--library-resize` 可验证已打开的普通书签在手机与平板布局间切换后仍可使用。后者仅用于竖屏模拟器，结束时恢复原有显示尺寸与密度。

在页面菜单中选「添加书签」可修改名称和网址。「在个人收藏中显示」控制这条书签是否出现在起始页。已有书签可从页面菜单、左滑书签列表或长按列表和起始页收藏来编辑。空名称保存为网址。多个窗口同时编辑一条书签时，先保存的修改会保留，另一份草稿会提示重新打开。旧版的书签和预置收藏会保留原顺序，预置收藏也可以改名或移除。

在专用 Android 模拟器上运行 `python tests/safari_motion.py 设备序列号 --bookmarks`，可验证新增、取消、改名、改址、重复网址和收藏开关。用 `--bookmark-conflict` 可复测双窗口编辑冲突，用 `--bookmark-menu --menu-record bookmark.mp4` 可录制长按书签、滑到编辑并松开的过程。
书签编辑器使用 LiquidKit 的玻璃表面、文本框和收藏开关。在网页上编辑时，玻璃取样当前网页；从资料库进入时，编辑器还会取样它下方的资料库面板。用 `--bookmark-glass` 可复测网页变色以及展开的面板对网页的遮挡。

在标签总览点「排列标签页」可按标题或网站整理当前组。固定标签保持原位，同一网站里的标签保留原来的相对顺序。普通组的排列在重启后保留。在测试电脑安装 OpenCV 和 NumPy 后，可用 `python tests/tab_overview.py 设备序列号 --arrange --record arrangement.mp4` 复测排列、卡片跟手距离和反向拖动后的回弹。

在标签总览里，按住卡片后继续拖动，可在同一组内换位。菜单已经弹出时，滑向菜单项并松手可执行命令，拖出菜单边缘可继续移动卡片。拖到网格上下边缘并停留可滚动到屏幕外的标签。固定标签可在置顶区域内换位。读屏操作也提供前移和后移。运行 `python tests/tab_overview.py 设备序列号 --manual-order --record reorder.mp4` 可复测。

有正文的网页可从页面菜单进入阅读器。阅读器保留标题层级、段落、引用、列表、表格、HTTP(S) 配图和链接。点 aA 调整字体、字号和纸张底色，有小标题时可从目录跳到相应章节。关闭阅读器可返回原网页；同一文档再次进入阅读器会回到上次阅读位置。外观偏好在重启后保留。用 `python tests/safari_motion.py 设备序列号 --reader --screens screenshots --menu-record reader.mp4` 验证阅读流程，用 `--reader-glass` 验证滚动配图经过浮动工具栏时的取色。

从「页面菜单 → 在页面中查找」输入文字，会在网页内高亮匹配项。点上下箭头或输入法的下一项可跳转。也可以在地址栏输入文字后点「在此页查找」。外接键盘支持 Ctrl+F 打开、Ctrl+G 跳到下一项、Ctrl+Shift+G 跳到上一项、Esc 关闭。查找栏在手机上随软键盘上移，在平板上显示在网页上方。运行 `python tests/safari_motion.py 设备序列号 --find --screens screenshots` 可以在手机上复测；平板加 `--tablet`。

在网页顶部向下拖，页面会随手指移动。玻璃刷新按钮出现后，继续拖过阈值再松手即可重新载入。松手前把手指往上收可以取消。网页内嵌列表、正在处理触摸手势的网页和设置了竖向 overscroll 禁用规则的区域保留自己的滚动行为。用 `python tests/pull_refresh.py 设备序列号 --record refresh.mp4` 复测，脚本会对照网页实际移动的像素和 HTTP 载入次数。

刷新表单提交后的页面时会询问是否重新提交。点取消会保留当前结果。运行 `python tests/pull_refresh.py 设备序列号 --form` 可用本地表单核验取消与确认时服务器收到的提交次数。

普通标签关闭后，最近 20 张会分别保留。两张标签即使停在同一网址也可单独恢复；有来源页时，列表会标出它们各自的来源。可长按工具栏的标签按钮进入「最近关闭」，也可在标签总览长按加号，或在网页上使用 Ctrl+Shift+T / Command+Shift+T。恢复时沿用原标签的桌面网站模式、阅读位置以及 WebView 保存的前进和后退记录。无痕标签不进入列表。旧版记录、WebView 提供程序升级或无法保存原生状态时，仍可按原网址打开。每张标签的原生导航状态最多 96 KiB，过长的历史可能会截短。运行 `python tests/closed_tabs.py 设备序列号` 可验证同网址双标签冷启动恢复，加 `--private` 验证无痕隔离。

阅读列表可切换「全部」和「未读」。从列表打开普通网页会标成已读。向右滑条目可标记已读或未读，向左滑可共享或删除。长按条目后，手指滑到菜单项再松开可直接执行操作。旧版保存的条目初始为未读，再次加入同一网址会把它放回未读列表顶部。阅读状态在各窗口间共享，关闭应用后仍会保留。运行 `python tests/safari_motion.py 设备序列号 --reading-list` 可验证手势、筛选和重启后的状态，加 `--menu-record reading.mp4` 可保存录像。在安装了旧版的专用测试设备上，加 `--upgrade-apk 新版APK路径` 可验证覆盖升级。手机布局可用 `--reading-list-glass` 核验展开面板上长按菜单的玻璃取样。

连接外接键盘后，Ctrl+L 可选中地址，Esc 可放弃修改。Ctrl+T 新建当前组的标签并聚焦地址栏，Ctrl+W 关闭当前标签。在地址栏按 Ctrl+Enter 可在后台打开输入的网址或搜索词，加 Shift 可在新标签中立即查看。Ctrl+[ 和 Ctrl+] 分别后退和前进，Ctrl+R 重新载入。Ctrl+Tab 和 Ctrl+Shift+Tab 在当前组循环切换，Ctrl+1 至 Ctrl+8 按标签条顺序选择，Ctrl+9 选最后一张。Ctrl+Shift+反斜线打开或收起标签总览，沿用手势入口的卡片动画。在总览里按 Esc 先退出搜索，再返回网页。

应用也识别系统传给它的 Command 组合键。部分 Android 设备会保留 Meta 键供系统使用，此时可使用 Ctrl。运行 `python tests/safari_motion.py 设备序列号 --browser-keys` 可在独立窗口验证快捷键、网页文本编辑、标签组及无痕隔离，加 `--menu-record keys.mp4` 可录制总览动画。

在平板布局，侧栏按钮和前进后退按钮各有独立的 LiquidKit 玻璃底座。第二行标签共用一条玻璃，选中项带有单独的高亮边缘。支持深色模式的网站可以按照系统外观显示自己的配色。平板模拟器可运行 `python tests/safari_motion.py 设备序列号 --tablet-strip --screens screenshots` 核对活动和后台标签下的取色，并检查网页收到的浅色与深色偏好。

平板工具栏左上角可打开侧栏，从中进入书签、阅读列表、历史记录和最近关闭的标签，也可切换普通、无痕和自建标签页组。点「完成」收起后，再次打开会回到该窗口上次查看的栏目。栏目内可点左上角返回、按系统返回键或向右拖动，拖回原位会取消。用 `python tests/safari_motion.py 设备序列号 --tablet-sidebar --screens screenshots` 可以复测侧栏导航、分组切换，并比较网页换色前后的玻璃像素。加 `--menu-record sidebar.mp4` 可录制返回手势。

确认下载后，地址栏旁会出现下载按钮。在手机上点它可拉起 LiquidKit 下载面板，在平板上会从按钮旁弹出下载列表。可查看传输进度、取消下载或点已完成的文件打开。文件保存在 Android 公共下载目录。从列表移除已完成的记录会保留文件。页面菜单中的「下载项目」也能打开列表，再点「打开系统下载目录」可以查看之前版本保存的文件。普通下载记录在各窗口共享，重启后保留。无痕下载记录仅在当前窗口的无痕会话内显示，用户主动保存的文件仍在下载目录中。

在专用 Android 模拟器上运行 `python tests/safari_motion.py 设备序列号 --downloads --screens screenshots`，可以用本地 HTTP 附件验证进度、文件内容、取消和重启。宽屏模拟器加 `--tablet` 可验证下载浮层的位置。

传输失败时可以点该记录重试。同名文件会依次使用「(2)」「(3)」等后缀，原文件会保留。运行 `python tests/safari_motion.py 设备序列号 --download-retry` 可复测 HTTP 失败后的重试以及同名文件的内容。

长按手机或平板的地址栏可复制当前页面的完整网址、编辑地址，或将剪贴板中的网址或搜索词直接提交到当前标签。网址中的路径、查询参数和片段会一起复制。菜单打开时只检查剪贴板的数据类型，选「粘贴并前往」时才读取内容。长按后可保持手指按住，划到菜单项松开。手机地址栏横划仍用于切换标签，收起后的域名条也能长按。在专用测试模拟器运行 `python tests/safari_motion.py 设备序列号 --address-menu --screens screenshots` 可验证复制、粘贴、菜单取色和收起后的入口。该测试写入测试网址到模拟器剪贴板，可加 `--menu-record address.mp4` 录制菜单。
测试文字搜索可使用 `--address-search`。脚本仅在专用模拟器上运行，临时离线检查当前引擎的搜索地址和查询词，结束后恢复原有的飞行模式与 Wi-Fi 状态。

地址栏可按标题或网址查找当前窗口中已经打开的标签，最多显示六个匹配项。点「切换到标签页」所在的一行可回到原来的阅读位置。同组内有多张相同网址的标签时，结果会注明各自在标签栏里的位置。普通浏览和无痕浏览分别搜索。外接键盘可用上下方向键选择建议，回车执行选中项。直接输入后按回车会打开输入的网址或搜索词。输入框和建议列表均使用 LiquidKit 玻璃。

运行 `python tests/safari_motion.py 设备序列号 --open-tab-search --screens screenshots` 可在独立窗口用本地网页验证原表单、滚动位置、跨组选择、无痕隔离和玻璃取色。加 `--menu-record search.mp4` 可录制键盘选择过程。

平板地址栏从工具栏中央向两侧展开。普通标签中，已有的个人收藏随面板出现，输入后切换到搜索建议。点面板外会收起玻璃面板，外接键盘可按 Esc 快速退出。用安装了 Pillow、NumPy 和 OpenCV 的 Python 运行 `python tests/safari_motion.py 设备序列号 --address-motion --menu-record address.mp4`，可在平板模拟器上记录原速动画，并逐帧检查放慢后的展开和收起。脚本结束时恢复系统动画设置。

1.31 的平板侧栏、地址栏和页面菜单参考了真实 iPad Safari 在同一网页上的连续录屏。侧栏宽 320 dp，滑入时让背景逐渐变暗约 20%。页面菜单宽 232 dp，以工具栏按钮为起点放大，略微越过目标尺寸后回落。点空白处会将菜单收回到按钮。运行 `python tests/safari_motion.py 设备序列号 --tablet-popup-motion` 可检查侧栏边缘和背景亮度，并通过模拟器录屏检查菜单展开及收回时的中间尺寸。

1.32 依据 iPad Safari 的长按录屏调整了链接预览。820 dp 宽的竖屏平板上，卡片约为 342 × 476 dp，与操作列表相距 20 dp。展开时背景变暗，点卡片后菜单文字先隐去，卡片收向原链接，随后淡入目标网页。打开菜单后重新按下某一行也能滑选，滑到列表外松手可取消。`--tablet-menu` 同时检查背景亮度、子菜单位置和滑选结果。
